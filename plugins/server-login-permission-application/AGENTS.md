# Server Login Permission Application

- Treat this directory as the only editable and distributable source for this plugin.
- Keep the Codex and CodeBuddy manifests aligned and pointed at the shared Skill.
- Never commit, print, quote, summarize, or persist Token values, token-signing values, Cookies, or `config/config.local.json`.
- Use only the production Zeus API unless a maintainer explicitly changes the local configuration; never accept an environment switch from ordinary ticket-request conversation.
- Never submit without a live validation pass, a generated confirmation ID, and the exact confirmation phrase `确认提交`.
- Never automatically retry a submission request.
- Run `npm test` in this directory and then at the marketplace root after changes.
